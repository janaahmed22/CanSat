# Arduino Simulation Project

## Files
- `project.ino` → Arduino source code
- `project.simu` → SimulIDE circuit file

## Circuit Details
- Potentiometer on A0
- LEDs on pins 10, 9, 8 (through resistors to GND)
- Buzzer on pin 6
- Powered via Arduino 5V and GND
